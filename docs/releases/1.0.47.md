# Ghost Nexora VPN 1.0.47

## Native routing hardening

- Every SSH and upstream-proxy socket is now excluded explicitly with
  `VpnService.protect(Socket)` before connect.
- Protected sockets are additionally bound to an Android physical `NOT_VPN`
  network when available.
- A rejected or unavailable socket protector fails closed with
  `VPN-LOOP-001`; the app does not risk routing the encrypted transport back
  into its own TUN.
- TCP latency probes now use the same protected physical path.

## Runtime architecture

- Added an executable capability manifest for SSH, VLESS/VMess, Trojan, and
  Hysteria2.
- Runtime logs now identify the real chain used by the selected profile.
- Confirmed AndroidLibXrayLite/Xray as the single native TUN owner. A redundant
  `hev-tun2socks` layer is not started over the same descriptor.
- SSH remains TCP through loopback SOCKS5 and JSch `direct-tcpip`.
- Hysteria2 remains provided by the bundled Xray core.
- BadVPN UDP-over-SSH, Hysteria v1, and separate Hysteria/Tun2Socks binaries are
  documented as unavailable rather than silently advertised.

## Validation

- Added architecture tests for `protect(Socket)` lifecycle and ordering before
  `Network.bindSocket`.
- Added a test matrix ensuring every enabled connection mode maps to a concrete
  bundled runtime and does not overstate UDP support.
- Bumped the application to `1.0.47 (47)`.
